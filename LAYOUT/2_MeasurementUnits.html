Measurement Units

Absolute Relative
Nunca cambian Relativos a algo más
px %: relative to the size of the container, parent element
pt vw: relative to the viewport
in vh: relative to the viewport
cm em: relative to the font size
mm rem: relative to the font size

El uso de una determinada unidad depende del problema que estés intentando resolver. Por cierto, para web solo usamos px.

Pruebas:

La unidad rem es ventajosa porque se basa en el tamaño de fuente raíz (html). Si el usuario o el navegador cambia el tamaño de fuente por defecto, todos los elementos que usan rem escalarán proporcionalmente, mejorando la accesibilidad y la adaptabilidad del diseño.

Por defecto el height de los block-level elements es 0 y el width 100%. Si añades elementos dentro, el height aumenta automaticamente.
