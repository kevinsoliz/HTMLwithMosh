Fonts gratis

    Formats

  • TTF
  • OTF
  • EOT
  • WOFF
  • WOFF 2.0

Las más eficientes son las dos últimas para web, están mas comprimidas. Necesitamos que el tamaño del archivo sea lo más pequeño posible para que la web cargue rápido. Después de formatear la fuente a woff o woff2, comprueba en "caniuse.com" si el formato es compatible con los navegadores.

Flash of Unstyled Text

Para probar esto: dev tools, Netowork, Disable cache, No throttling... Esto es el FOUT (Flash of Unstyled Text), que es cuando el navegador muestra el texto sin estilo antes de que se cargue la fuente.

System Font Stack

Es una forma de usar las fuentes del sistema del usuario, sin tener que cargar una fuente externa. Se usa para mejorar la velocidad de carga y la experiencia del usuario. No FOUT, native look, better experience, no loading time.
